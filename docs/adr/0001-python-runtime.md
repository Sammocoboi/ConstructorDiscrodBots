# 0001. Runtime на Python

- Статус: принято
- Дата: 2026-10-21

## Контекст

Backend написан на Python/Django. Runtime должен подключаться к Discord Gateway,
исполнять сценарии и разделять код блоков с backend-валидацией. Команда знает Python;
второй язык (Node.js) увеличивает стоимость поддержки и риск расхождения контрактов.

## Решение

Runtime — Python-сервис на `discord.py`, отдельный процесс/контейнер. Общие модели
конфигурации описываются JSON-схемами, а не импортом Django-моделей.

## Последствия

- Один язык на backend и Runtime, общие инструменты (ruff, pytest).
- Можно переиспользовать реестр блоков и выражения.
- discord.py задаёт модель event loop; тяжёлые блоки должны исполняться в пуле потоков/процессов.
- Node.js-экосистема Discord (discord.js) недоступна — принято осознанно.
