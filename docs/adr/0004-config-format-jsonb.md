# 0004. Конфигурация бота — JSONB с версией схемы

- Статус: принято
- Дата: 2026-10-21

## Контекст

Конфигурацию одновременно читают backend (валидация, версии), Runtime (исполнение) и
frontend (редактор). Нужна гибкая схема без миграции таблиц на каждый новый блок.

## Решение

- Конфигурация хранится в JSONB: `bot_drafts.content`, `bot_versions.content`.
- Корневой объект содержит `schema_version`, `profile`, `modules`, `commands`, `flows`, `messages`, `variables_schema`.
- Лимит документа — 2 МБ; секреты запрещены.
- Схема и реестр блоков описаны в `docs/config-schema.md` и `docs/block-registry.md`
  (владелец — Шухратжон). Изменения — только через PR.
- Валидация — на backend (JSON Schema + семантические проверки) и повторно в Runtime перед исполнением.

## Последствия

- Гибкое расширение блоков и модулей без миграций.
- Нужны миграции схемы конфигурации и contract-тесты.
- JSONB-индексы только для реально используемых путей (например, `flows`).
